      #简繁转换工具

      简繁转换工具 是一款本地运行的中文文本转换工具，支持简体、繁体（台湾 / 香港 / OpenCC 模式）、日本新字体之间任意方向的转换。提供两个快捷按钮（繁→简、简→繁）+ 自定义语言对 + 用户可编辑的保护词典 + 批量文件处理。

      #支持的语言代号

      工具内部使用 6 个语言代号：

      代号含义
      cn简体中文
      tw繁体中文（台湾），仅字形转换
      twp繁体中文（台湾）+ 地区词汇转换 —— 在 tw 基础上额外转换台湾词汇（视频↔影片、幼儿园↔幼稚園 等）
      hk繁体中文（香港），香港本地字形
      tOpenCC 模式繁体，标准字形转换
      jp日本新字体（Shinjitai）

      #页面布局

      页面分两栏：

      • 左栏：输入区（上传 + 文本框）+ 两个快捷按钮 + 结果卡
      • 右栏：转换设置 + 自定义语言 + 保护词典面板

      #快捷转换（左栏）

      两个主操作按钮：

      • 繁→简：从某种繁体转到简体
      • 简→繁：从简体转到某种繁体

      按钮使用哪种"繁体"由右侧「转换设置」中的词汇转换开关决定：

      词汇转换开关繁→简 (t2s) 等价简→繁 (s2t) 等价
      开启twp → cncn → twp
      关闭t → cncn → t

      #自定义语言（右栏）

      需要 tw↔hk、t↔jp 等其他组合时使用：

      1. 在「源语言」下拉中选择输入语言
      2. 在「目标语言」下拉中选择输出语言
      3. 点击「自定义转换」执行

      ⚠️ 注意：保护词典只对涉及简体的转换生效（如 s2t、t2s）。选用不涉及简体的语言对（如 tw↔hk）时，已有的保护词条会被跳过，工具会显示"当前规则未生效"提示。

      #转换设置（右栏）

      4 个开关：

      • 词汇转换：控制快捷按钮的繁体类型（见上表）。"自定义语言"卡片不受此开关影响
      • 智能换行：开启后根据中文标点合并断行（OCR 修复利器）
      • 单文件模式：开启后一次仅处理一个文件，新上传的文件替换当前文件
      • 处理后自动导出：开启后转换结果直接下载为文件，不在页面显示预览（适合大批量处理）

      #保护词典（Protected Dictionary）

      工具的进阶功能，允许用户定义"不被转换"的词组清单。

      #工作机制

      • s2t 规则：简→繁方向生效（from 是简体词，to 是希望保留的繁体写法）
      • t2s 规则：繁→简方向生效
      • 两套规则独立管理、独立存储

      #何时应用

      保护规则仅在涉及简体的转换方向生效：

      • ✅ cn → tw/twp/hk/t/jp → 应用 s2t 规则
      • ✅ tw/twp/hk/t/jp → cn → 应用 t2s 规则
      • ❌ tw ↔ hk、t ↔ jp 等纯繁体间转换 → 不应用规则
      • ❌ 总开关关闭时 → 不应用任何规则

      #管理保护规则

      点击右下角保护词典面板的「管理规则」按钮，打开抽屉：

      • 切换 s2t / t2s 方向 tab
      • 增删改单条规则（from → to）
      • 批量导入/导出（与小说排版工具共享同一份词典）

      #典型用法

      • 把"机器人"加进 s2t 规则的"to"字段保留为"机器人"，避免被转成"機器人"（常见技术词）
      • 把"软件"加进 s2t 规则强制保留简体写法
      • 把繁体人名加入 t2s 规则避免被错误简化

      #文件上传

      • 拖拽或点击上传，支持 .txt、.csv、.json、.md 等富文本格式
      • 默认多文件模式，可上传一批一起处理
      • 多文件状态下文本框被隐藏，处理完每个文件按原名导出

      #结果区

      单文件转换完成后显示结果卡，提供：

      • 复制：一键复制结果
      • 导出文件：以原文件名（或 jianfan.txt）下载
      • 编辑结果：直接修改结果文本

      启用「处理后自动导出」时跳过结果显示直接下载。

      #适用场景

      • 文档本地化：两岸三地内容同步（简体陆版 / 繁体台版 / 繁体港版）
      • OCR 文本优化：结合智能换行修复扫描识别后的断行
      • 学术 / 古籍：处理繁体文献时使用保护词典保留专有名词
      • 内容创作：博客、小说一键产出简繁双版本
      • 批量数据：处理含中文字段的 .json / .csv / 多个 TXT

      #为什么是本地运行？

      本工具基于 js-opencc（OpenCC 的 JavaScript 移植）开发，字典从 OpenCC 官方同步。完全在浏览器本地执行，文件不上传服务器，敏感数据可放心处理。
