      #文本工具集

      四款互补的纯文本处理工具，覆盖格式转换 → 内容清洗 → 分段切片 → 通用文本操作。全部浏览器本地运行，敏感数据不外发。

      #如何选择

      我要做…用这个
      简繁体互转、台湾 / 香港地区词中文转换
      网络小说排版、章节标题修复、去广告小说处理
      长文本按字数 / 段落 / 分隔符切分文本分割
      正则匹配、去重、批量加前后缀、行操作多功能文本处理

      #共同能力

      • 浏览器本地：文件读取、解析、处理都在本地完成，敏感数据不外发
      • 批量处理：四个工具都支持一次粘贴多份文本 / 批量上传文件
      • 保护词典：中文转换、小说处理都支持自定义"不处理"的词组（如 iPhone、OpenAI 等专有名词）
      • 可链式使用：先用文本分割切大文档 → 用文本处理跑正则 → 用中文转换出繁体版

      #典型组合

      • 网文阅读优化：小说处理去广告 + 修章节标题 → 中文转换转繁体台湾 → 批量导出
      • AI 喂料预处理：长文档用文本分割按字数切到 4K token 块 → 多功能文本处理跑正则清洗 → 批量导出 .txt
      • 多语言资料整理：多功能文本处理过滤掉日文行 → 中文转换转简体 → 文本分割按段落切片
