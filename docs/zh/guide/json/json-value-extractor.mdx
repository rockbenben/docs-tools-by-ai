# JSON 值提取器

[JSON 值提取器](https://tools.newzone.top/zh/json-value-extractor) 使用 JSONPath 表达式从 JSON 数据中提取特定值。只需指定要提取的节点路径，并可选择为提取的值添加前缀和后缀。

![JSON 值提取器界面](/img/json-value-extractor-zh.webp 'JSON 值提取器使用界面')

## 使用方法

1. 上传 JSON 文件或在文本区域粘贴 JSON 内容
2. 输入 JSONPath 表达式（无需包含开头的 $）来提取值
   - 示例：`data.title` 提取 data 下的所有 title 值
   - 示例：`messages[*].text` 提取所有消息中的文本
3. 可选择为每个提取的值添加前缀和后缀文本
   - 使用 `{value}` 作为占位符，在前缀/后缀中包含提取的值
4. 点击"开始处理"提取值

该工具支持提取字符串、数字和布尔值。如果尝试提取对象或数组，工具将显示错误消息并跳过该节点。

对于大型 JSON 文件，启用"大文件模式"可以更高效地处理大数据集。
