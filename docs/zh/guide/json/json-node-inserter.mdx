# JSON 节点插入工具

[JSON 节点插入工具](https://tools.newzone.top/zh/json-node-inserter) 是一个高效的数据结构优化工具，可在 JSON 文档中的指定节点后插入一个或多个新节点，使数据结构更加合理与高效。

![JSON 节点插入工具界面](/img/json-node-inserter-zh.webp 'JSON 节点插入工具使用界面')

## 功能特点

- 可在指定节点后精确插入多个新节点
- 多节点插入支持逗号分隔（支持中英文逗号）
- 批量插入节点，提高数据处理效率

## 使用方法

1. **输入 JSON 数据**
   - 拖拽上传 JSON 或文本文件
   - 或直接在文本框中粘贴 JSON 内容
   - 对于大型 JSON 文件，可勾选"大文件模式"

2. **设置插入参数**
   - **目标节点**：输入要查找的节点名称（确定插入位置）
   - **新节点**：输入要插入的节点名称，多个节点用逗号分隔

3. **处理与导出**
   - 点击"开始处理"按钮执行插入操作
   - 处理结果将显示在下方文本区域
   - 可选择复制完整结果、仅复制节点值或下载处理后的文件

## 使用提示

- 确保输入的 JSON 格式正确，否则将无法处理
- 目标节点必须存在于 JSON 中，否则将提示错误
- 新节点将按照输入顺序插入到目标节点后
- 节点名称如为纯数字，将按数值大小自动排序并置于前面
- 对于大型 JSON 文件，建议使用"大文件模式"以提高性能

## 应用场景

- 优化 JSON 配置文件结构
- 调整 API 响应数据格式
- 批量添加新属性到现有数据结构
- 快速调整系统配置参数顺序
