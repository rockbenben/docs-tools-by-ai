# JSON 节点插入工具

[JSON 节点插入工具](https://tools.newzone.top/zh/json-node-inserter) 是一个高效的数据结构优化工具，可在 JSON 文档中的指定字段后插入一个或多个新字段，使数据结构更加合理与高效。

![JSON 节点插入工具界面](/img/json-node-inserter-zh.webp 'JSON 节点插入工具使用界面')

## 功能特点

- 可在指定字段后精确插入多个新字段
- 支持候选字段快选（Chips）：自动提取源数据中的字段并一键点选为参考字段
- 多字段插入支持逗号分隔（支持中英文逗号）
- 批量插入字段，提高数据处理效率

## 使用方法

1. **输入 JSON 数据**
   - 拖拽上传 JSON 或文本文件
   - 或直接在文本框中粘贴 JSON 内容
   - 对于大型 JSON 文件，改用文件上传而不是粘贴

2. **设置插入参数**
   - **参考字段**：输入参考字段名称，或直接点击输入框下方自动生成的字段快选芯片快速挑选
   - **插入新字段**：输入要插入的新字段名称，多个字段用逗号分隔

3. **处理与导出**
   - 点击"开始处理"按钮执行插入操作
   - 处理结果将显示在下方文本区域
   - 可选择复制完整结果、仅复制节点值或下载处理后的文件

## 使用提示

- 确保输入的 JSON 格式正确，否则将无法处理
- 参考字段必须存在于 JSON 中，否则将提示错误
- 新节点将按照输入顺序插入到目标节点后
- 节点名称如为纯数字，将按数值大小自动排序并置于前面
- 对于大型 JSON 文件，建议用文件上传代替粘贴，页面更流畅

## 应用场景

- 优化 JSON 配置文件结构
- 调整 API 响应数据格式
- 批量添加新属性到现有数据结构
- 快速调整系统配置参数顺序
