# JSON 键值映射工具

[JSON 键值映射工具](https://tools.newzone.top/zh/json-value-transformer) 可以在 JSON 数据结构中实现值的迁移和复制。该工具特别适用于多语言内容同步、配置文件更新以及复杂 JSON 结构的数据转换。

## 核心功能

- **键值映射转换**：通过指定输入键和输出键，将一个路径的值复制到另一个路径
- **预设模板**：内置多语言翻译模板，自动将英文内容映射到多种语言字段
- **自定义映射**：灵活创建多组键映射规则，处理复杂的数据迁移需求

## 使用方法

1. **选择映射模式**：
   - 切换到"预设映射 AIShort"使用内置的多语言映射模板
   - 切换到"自定义映射"创建自己的键值映射规则

2. **输入 JSON 数据**：
   - 直接粘贴 JSON 文本到文本框
   - 或拖拽上传 JSON/TXT 文件

3. **定义映射规则**（自定义模式）：
   - 输入键：指定要读取值的 JSONPath 路径
   - 输出键：指定要写入值的 JSONPath 路径
   - 可添加多组映射规则

4. **处理数据**：
   - 点击"开始处理"按钮执行映射转换
   - 处理结果会显示在右侧结果区域

5. **结果操作**：
   - 复制完整 JSON 结果
   - 复制仅节点内容（去除外层包装）
   - 下载为 JSON 文件

## 应用场景

- 多语言内容管理：将英文内容映射到多种语言字段
- 数据结构重组：在复杂 JSON 结构中迁移和复制值
- 配置文件同步：在不同环境配置间同步特定值

通过 JSONPath 的强大定位能力，本工具可以精确处理嵌套多层的复杂 JSON 结构，确保数据迁移的准确性和完整性。
