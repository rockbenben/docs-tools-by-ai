# 文本分割器

[文本分割器](https://tools.newzone.top/zh/text-splitter) 是一款长文本处理工具，适用于 ChatGPT、DeepSeek 等 AI 模型的上下文切分，以及文档编辑、社交媒体内容整理等场景。工具提供**四种切分模式**：符号、长度、中文分段、英文分段，并支持批量导出与 ZIP 打包。

![文本分割器界面](/img/text-splitter-zh.webp '文本分割器使用界面')

:::tip 30 秒上手

1. 粘贴或上传长文本
2. 选 **切分模式**：
   - 按句号 / 问号逐句切开 → **符号**（默认）
   - 切成固定字符块（喂给 AI）→ **长度**
   - 中文长文按段 → **中文**
   - 英文按句 → **英文**
3. 符号模式填分隔符（可调「每段分隔符数」）；长度模式填字符数，另可填分隔符让切点对齐到 `. ? !`
4. 点 **处理** → 一次性导出（≤ 3 段逐个下载，> 3 段自动打 ZIP）

:::

## 四种切分模式

四种模式通过顶部的 Segmented 选择器切换，标签为「符号 / 长度 / 中文 / 英文」，鼠标悬停可看到每种模式的详细说明。每种模式只会显示相关的配置项，配置互不干扰。

### 1. 符号（默认）

纯按分隔符切分：每遇到一个分隔符就切开一段，分隔符保留在段尾，不受字符数限制。

- **分隔符**：必填，决定在哪里切
- **每段分隔符数**：默认 1，即每个分隔符都切一刀；填 2 表示相邻两个最小段合并为一段，填 3 合并三段，以此类推。适合"按句切分但每段想要 2–3 句"的场景

连续出现或位于行首的分隔符不会切出空段，多余的分隔符会并入相邻段落，导出合并文本时可还原原始内容。

### 2. 长度

按设定的字符数把文本切成块。默认 2000 字符（最小 1），适合 LLM 上下文切分。**分隔符**为可选项，填了就生效，无需额外开关：

- **分隔符填写**：按长度切块，切点自动对齐到最邻近的分隔符，避免句子被截断
- **分隔符留空**：硬按长度切，不管句子边界

分隔符输入框支持：

- 手动输入，如 `。 ？ ！`（多个符号用空格分隔）
- 点击「中日韩」一键填充 `。 ？ ！`
- 点击「英文/拉丁」一键填充 `. ? !`
- 转义字符：`\n`（换行）、`\r`（回车）、`\t`（制表符）、`\s`（空格）、`\\`（反斜杠）

分隔符切分会把符号保留在每段末尾。

### 3. 中文

按中文段落规则切分：根据中文标点和换行符智能识别段落边界，不改变段落内的换行。适合中文文章、博客内容的段落化。无需额外配置。

### 4. 英文

使用 compromise NLP 库的英文句子算法识别边界，每句一段。适合英文文档、邮件、论文的段落化切分。无需额外配置。

## 通用设置

所有模式共享以下两项设置：

- **隐藏结果**：切分结果过多（默认 >500 段时自动触发）可开启本项隐藏预览，避免页面卡顿。此时仍可导出。
- **导出文件名**：自定义导出文件的基础名。默认用上传文件名，未上传则用 `split_text`。后缀默认为 `.txt`，也可手动填写其他后缀。

## 导出

- **导出合并文本**：所有段落合并为单文件，段落间用双换行分隔。
- **批量导出**：段落数 ≤ 3 时逐个下载，> 3 时自动打包 ZIP，避免一次下载过多文件。
- **单段复制**：每段卡片右上角的复制按钮，点击后按钮图标变为打勾确认。

## 常见用法

- **LLM 输入切分**：选**长度**模式，字符数 2000–4000，分隔符填 `。 ？ ！` 或 `. ? !`，切点自动对齐到句末
- **按句切分**：选**符号**模式，分隔符填 `。 ？ ！`（或英文结束符），间隔保持 1
- **每 3 句一段**：选**符号**模式，分隔符填 `。 ？ ！`，「每段分隔符数」填 3
- **按段落切分**：选**中文**或**英文**模式
- **代码/Markdown 切分**：选**长度**模式 + 转义字符 `\n\n` 作为分隔符

工具完全在浏览器本地运行，不会上传任何内容到服务器。
