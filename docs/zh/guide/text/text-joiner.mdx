# 文本拼接

[文本拼接](https://tools.newzone.top/zh/text-joiner)（Text Joiner）解决的是"两份列表要按行合起来"的问题：一列是名称、一列是链接，要拼成 Markdown 链接；一列是 ID，要拼成 SQL `IN (...)`；几列表格数据要拼回 CSV。**逐行按行号对齐 + 模板占位符**，一次配置批量出结果。

它与 [文本分割](./text-splitter.mdx) 正好互为逆操作，也常与 [多功能文本处理](./text-toolbox.mdx) 的批量前后缀配合使用——后者只能给单列加固定前后缀，跨列拼接得用本工具。

![文本拼接界面](/img/text-joiner-zh.webp '文本拼接使用界面')

:::tip 30 秒上手

1. 左侧填 **列输入**：第 1 列、第 2 列各粘一份文本（每行一条）
2. 点一个**预设**（CSV / Markdown 链接 / SQL IN…），或自己写**逐行模板**如 `{1},{2}`
3. 右侧结果实时更新，确认后复制

:::

## 列输入

- **输入列数**：1～8 列，按需增减
- **Excel / 表格粘贴自动拆列**：从 Excel、Google Sheets 复制的多列内容，粘贴到任意一个列框，会按 Tab 自动拆到各列（提示「已按表格拆分：N 行 × M 列」）。超过列数上限时只填入前 8 列并给出提示。不想要这个行为可以关掉「Excel/表格粘贴自动拆列」开关
- **行数显示**：每列标题旁显示当前行数，方便发现两列行数不一致
- **加载示例**：不确定怎么用时，点一下就有可运行的样例数据

## 逐行模板

模板决定**每一行**输出什么，用 `{1}`、`{2}` 引用各列的当前行：

| 模板              | 输入（第 1 / 2 列） | 输出                       |
| ----------------- | ------------------- | -------------------------- |
| `{1},{2}`         | `苹果` / `apple`    | `苹果,apple`               |
| `- [{1}]({2})`    | `官网` / `https://…` | `- [官网](https://…)`      |
| `'{1}'`           | `A001`              | `'A001'`                   |

未定义的列号会原样保留，不会被替换成空字符串。点击列标题旁的 `{N}` 芯片可直接把该占位符插入模板光标处。

### 内置预设

点击即填好模板、连接符与前后缀四项配置：

- **CSV** / **引号 CSV** / **TSV**：表格数据回填
- **Markdown 列表** / **Markdown 链接**：`- {1} {2}` / `- [{1}]({2})`
- **JSON 数组**：每行输出一个对象（`{"c1": "…", "c2": "…"}`），整体包上 `[ ]` 并用 `,` 连接
- **SQL IN**：输出 `IN ('a', 'b', 'c')`
- **SQL VALUES**：输出完整的 `INSERT INTO table (col1, col2) VALUES ('…', '…'), …;`

预设按当前列数动态生成——把列数改成 3，CSV 预设自动变成 `{1},{2},{3}`。

## 整体拼接

结构是 **前缀 · 行 ⟨连接符⟩ 行 · 后缀**：

- **行间连接符**：每行之间插入什么，默认换行 `\n`；SQL IN 用 `, `
- **整体前缀 / 后缀**：整个结果的开头与结尾，例如 JSON 数组的 `[\n` 与 `\n]`

连接符与前后缀支持 `\n`、`\t` 等转义字符（模板本身不做转义解析，需要真 Tab 就直接输入 Tab）。

## 处理方式

- **列行数不同时**：
  - **补空**（默认）：按最长列输出，缺失的位置代入空字符串
  - **截断**：按最短列输出，多余的行丢弃
- **跳过全空行**（默认开启）：某一行所有列都为空时不输出该行

## 我的模板

自己调好的配置可以存下来复用：

- **另存为模板 / 更新到当前模板 / 删除模板**：按名字管理多套配置
- **导出配置 / 导入配置**：导出 JSON 文件（含所有模板与当前设置），换设备或分享给同事时导入即可

## 场景配方

下表以第 1 列 = `Alice / Bob`、第 2 列 = `12 / 15` 为例，列出每种场景的完整四项配置。

| 场景                 | 逐行模板         | 行间连接符 | 整体前缀                              | 整体后缀 | 输出                                                     |
| -------------------- | ---------------- | ---------- | ------------------------------------- | -------- | -------------------------------------------------------- |
| **CSV 行**           | `{1},{2}`        | `\n`       | —                                     | —        | `Alice,12` ⏎ `Bob,15`                                    |
| **Markdown 列表**    | `- {1}（{2}）`   | `\n`       | —                                     | —        | `- Alice（12）` ⏎ `- Bob（15）`                          |
| **Markdown 链接**    | `- [{1}]({2})`   | `\n`       | —                                     | —        | `- [Alice](12)` ⏎ `- [Bob](15)`                          |
| **SQL `IN (...)`**   | `'{1}'`          | `, `       | `IN (`                                | `)`      | `IN ('Alice', 'Bob')`                                    |
| **SQL `INSERT`**     | `('{1}', {2})`   | `,\n`      | `INSERT INTO t (name, score) VALUES\n` | `;`      | `INSERT INTO t (name, score) VALUES` ⏎ `('Alice', 12),` ⏎ `('Bob', 15);` |
| **JSON 数组**        | `{"n": "{1}", "v": {2}}` | `,\n` | `[\n`                              | `\n]`    | `[` ⏎ `{"n": "Alice", "v": 12},` ⏎ `{"n": "Bob", "v": 15}` ⏎ `]` |
| **单列加引号**       | `"{1}"`          | `,`        | —                                     | —        | `"Alice","Bob"`                                          |
| **批量改文件名**     | `mv {1} {2}`     | `\n`       | —                                     | —        | `mv Alice 12` ⏎ `mv Bob 15`                              |

以上大多有对应的一键预设（CSV / TSV / Markdown 列表 / Markdown 链接 / JSON 数组 / SQL IN / SQL VALUES / 引号 CSV），点一下即把四项配置填好，再按需微调。

### 典型工作流

- **表格数据入库**：Excel 复制多列 → 粘进任意列框自动拆列 → 点 **SQL VALUES** 预设 → 复制出完整 `INSERT` 语句
- **给一批 ID 拼查询条件**：把 ID 列表粘进第 1 列 → 点 **SQL IN** 预设 → 直接粘进 `WHERE id IN (...)`
- **给文档批量做外链列表**：标题一列、URL 一列 → **Markdown 链接** 预设 → 粘进 Markdown 文档
- **单列批量格式化**：把「输入列数」调成 1，模板写 `{1} —— 已完成`，就是一个逐行加前后缀的工具
- **与文本分割互为逆操作**：用 [文本分割](./text-splitter.mdx) 把长文按符号切成多段 → 处理完再用本工具按模板拼回去

工具完全在浏览器本地运行，**不上传任何数据**。
