# 本地批量简繁转换

[简繁转换工具](https://tools.newzone.top/zh/chinese-conversion) 是一款可在本地运行的中文文本转换工具，支持简体中文、繁体中文（台湾/香港）、OpenCC 模式繁体以及日本新字体之间的相互转换。该工具支持批量文档导入与一键转换，转换结果将以原文件名自动导出，全程无需联网，有效保障用户隐私与数据安全。

![简繁转换工具界面](/img/chinese-conversion.gif '简繁转换工具使用界面')

## 核心功能一览

- 多语言支持：兼容简体、港台繁体、OpenCC 繁体、日文新字体等多种转换模式
- 批量处理：可同时上传多个文档，一键完成批量转换
- 智能换行：优化 OCR 文本或断行文本的格式排版
- 本地运行：无需联网，转换数据仅在本地浏览器中处理
- 转换精准：基于 [OpenCC](https://github.com/BYVoid/OpenCC) 引擎，支持地区词汇差异转换，并内置自定义词汇修正

## 转换模式

### 快捷转换

工具提供两个主操作按钮和一个词汇转换开关：

- **繁➔简**：将繁体中文转换为简体中文
- **简➔繁**：将简体中文转换为繁体中文
- **转换地区词汇**（开关）：启用后，转换时会同时转换台湾地区惯用词汇（如：视频↔影片、幼儿园↔幼稚園）

### 自定义语言

右侧有一个独立的"自定义语言"卡片，可灵活选择源语言与目标语言：

1. 在"源语言"下拉中选择输入文本语言
2. 在"目标语言"下拉中选择所需输出语言
3. 点击"自定义转换"按钮执行转换

例如，可将繁体（台湾）转换为繁体（香港），或进行日文新字体转换。

## 支持的语言格式

| 语言类型                | 描述                                            |
| ----------------------- | ----------------------------------------------- |
| 简体中文                | 标准中文简体                                    |
| 繁体中文（台湾）        | 台湾地区使用的标准繁体字形                      |
| 繁体（台湾）+词汇转换   | 台湾用词与简体词汇互转（如“自行车” → “腳踏車”） |
| 繁体中文（香港）        | 香港本地繁体字形及用词                          |
| 繁体中文（OpenCC 模式） | 基于 OpenCC 转换标准                            |
| 日文新字体              | 支持与日本现代汉字字体之间的相互转换            |

## 高级功能设置

### 智能换行

针对 OCR 识别或段落被错误断开的情况，工具提供“智能换行”功能。该功能依据段落末尾是否为中文标点（如“。”、“？”、“！”、“…”、“...”或“---”）判断是否自动合并下一行，并在适当位置插入换行符，从而优化排版效果，提升文本可读性。

### 设置面板开关

右侧"转换设置"卡片中的四个开关：

- **转换地区词汇**：启用后同时转换台湾地区惯用词汇（如：视频↔影片、幼儿园↔幼稚園）
- **智能换行**：依据段落末尾标点判断是否合并下一行，优化排版
- **单文件模式**：启用后一次仅处理一个文件，新上传的文件替换当前文件
- **处理后自动导出**：启用后转换结果直接下载，不在页面显示预览，适合批量处理

## 使用方式

### 文件上传

支持拖拽上传或点击选择文件，兼容多种文本格式（如 `.txt`、`.csv`、`.json` 等）。

### 文本粘贴

支持将文本内容直接粘贴至编辑框，实时显示字符数与行数，适合快速预览与测试。

### 结果处理方式

转换完成后，用户可：

- 复制结果：一键复制转换文本至剪贴板
- 导出文件：以原文件名下载为 `.txt` 文件
- 编辑结果：直接在结果区域修改转换后的内容

## 适用场景

- 文档本地化：适用于简繁文档发布、两岸三地网站内容同步
- OCR 文本优化：结合智能换行，重构扫描识别后的内容格式
- 学术研究：简化古籍、港台学术资料等繁体文献的处理流程
- 内容创作：支持博客、小说等内容的简繁体版本发布
- 数据处理：适合批量处理含中文数据的 `.json`、`.csv` 等格式文件

## 自定义词汇修正

工具支持自定义词汇修正功能。如需添加自定义词汇，可在 [js-opencc](https://github.com/rockbenben/js-opencc) 仓库的 `data/custom/` 目录中编辑词汇文件。

## 为什么开发本工具？

在处理中文文本的实际工作中，简繁转换是一项常见却容易被忽视的需求。许多主流在线工具虽功能齐全，却需要将文本上传至远程服务器，带来数据隐私与安全风险。

为此，本工具基于 [OpenCC](https://github.com/BYVoid/OpenCC) 开发，数据字典直接从 OpenCC 官方同步。无需联网、纯本地运行，既满足了功能需求，也保障了使用过程中的数据私密性。
