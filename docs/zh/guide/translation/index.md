# 翻译功能

在日常使用中，特别是进行项目开发时，文本翻译常常成为一个令人头疼的问题。尽管市面上已有许多翻译工具，但它们往往存在以下不足：

- 并非完全免费；
- 格式支持不够全面；
- 不支持批量文件翻译。

为了解决这些问题，我整合了多个翻译 API，并针对不同文件格式（如 JSON、Markdown、字幕文件）开发了专用的翻译工具，提供更高效、灵活的翻译体验。

使用流程：选择翻译 API -> 设置源语言和目标语言 -> 开始翻译

## 功能亮点

- **翻译缓存**：自动本地缓存翻译结果，避免重复调用，节省时间和 API 费用。  
- **多接口选择**：提供 3 种免费翻译方式、3 种商业级翻译 API，以及 5 种 AI LLM（大模型）接口，满足不同需求。  
- **多语言支持与国际化**：支持 35 种主流语言（英语、中文、日语、韩语、法语、德语、西班牙语等），还可将同一字幕文件同时翻译成多种语言，满足国际化需求。
