# 翻译工具

:::tip 快速介绍
Tools By AI 翻译工具是一套面向开发者的免费批量翻译工具，覆盖字幕（SRT/ASS/VTT/LRC）、Markdown 和 JSON i18n 三种格式。集成 9+ 种 AI LLM 和 4 种商业翻译 API，支持 70+ 语言、本地缓存复用和上下文关联翻译，秒级完成一整集视频或一份项目文档。
:::

在日常使用中，特别是进行项目开发时，文本翻译常常成为一个令人头疼的问题。尽管市面上已有许多翻译工具，但它们往往存在以下不足：

- 并非完全免费；
- 格式支持不够全面；
- 不支持批量文件翻译。

为了解决这些问题，我整合了多个翻译 API，并针对不同文件格式（如 JSON、Markdown、字幕文件）开发了专用的翻译工具，提供更高效、灵活的翻译体验。

## 使用流程

选择翻译 API → 设置源语言和目标语言 → 开始翻译

## 功能特色

- **翻译缓存**：自动本地缓存翻译结果，避免重复调用，节省时间和 API 费用
- **多接口选择**：提供多种免费翻译方式、4 种商业级翻译 API，以及超过 9 种 AI LLM（大模型）接口
- **多语言支持**：支持 70+ 种主流语言，可将同一文件同时翻译成多种语言
- **格式专用优化**：针对不同文件格式提供专门的翻译工具
