# JSON Tools

Seven complementary tools that take you from **read** → **edit** → **add** → **cross-dataset sync**. All share the same JSONPath syntax so they chain naturally.

## Pick the Right Tool

| I want to…                                | Use                                                                  |
| ----------------------------------------- | -------------------------------------------------------------------- |
| Extract specific fields from JSON         | [**JSON Value Extractor**](./json-value-extractor.mdx)               |
| Batch add prefix/suffix, replace, overwrite | [**JSON Node Edit**](./json-node-edit.mdx)                         |
| Insert new fields after a specific node   | [**JSON Node Inserter**](./json-node-inserter.mdx)                   |
| Sort JSON arrays (with optional grouping) | [**JSON Sort & Classify**](./json-sort-classify.mdx)                 |
| Swap values of two keys                   | [**JSON Value Swapper**](./json-value-swapper.mdx)                   |
| Copy fields across JSON / key remap       | [**JSON Value Transformer**](./json-value-transformer.mdx)           |
| Sync two JSON datasets by ID              | [**JSON Match & Update**](./json-match-update.mdx)                   |
| Translate i18n JSON into multiple languages | [JSON Translate](../translation/json-translate/index.mdx) (in Translation Tools) |

## Shared Capabilities

- **Browser-local processing**: JSON parsing, JSONPath queries, and all edit operations run in your browser — source never uploads to a server
- **Unified JSONPath syntax**: `$..title`, `$.products[*].name`, nested paths like `zh.name` — same expressions across all seven tools
- **Large-file mode**: oversized JSON hides the textarea and routes through pure file I/O so tens of MB stay smooth
- **Chainable**: pull fields with Extractor, batch-edit with Node Edit, regroup with Sort & Classify — a full pipeline without writing a script

## Common Combinations

- **i18n dictionary cleanup**: Value Extractor pulls every `title` → translate/review → Node Edit overwrites them back
- **Product catalog regroup**: Sort & Classify by category + price descending → Node Edit adds a promo prefix
- **Dataset sync**: Export JSON A from the main DB and JSON B from CRM → Match & Update merges B's fresh fields into A by ID
