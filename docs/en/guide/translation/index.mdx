# Translation Tools

In daily use, especially during project development, text translation often becomes a headache. Although there are many translation tools on the market, they often have the following shortcomings:

- They are not completely free.
- Format support is not comprehensive enough.
- They do not support batch file translation.

To solve these problems, I have integrated multiple translation APIs and developed specialized translation tools for different file formats (such as JSON, Markdown, and subtitle files) to provide a more efficient and flexible translation experience.

## Usage Flow

Select Translation API → Set Source and Target Languages → Start Translation

## Features

- **Translation Cache**: Automatically caches translation results locally to avoid redundant calls, saving time and API costs.
- **Multiple API Options**: Offers 3 free translation methods, 3 commercial-grade translation APIs, and 6 AI LLM (Large Language Model) interfaces.
- **Multi-language Support**: Supports 50+ major languages and can translate the same file into multiple languages simultaneously.
- **Format-Specific Optimization**: Provides specialized tools optimized for different file formats.
