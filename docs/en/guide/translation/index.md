# Translation Function

In everyday use, especially during project development, text translation can often be a headache. Although many translation tools are available, they usually have the following shortcomings:

- They are not completely free.
- Their format support is limited.
- They do not support batch file translation.

To solve these problems, I have integrated multiple translation APIs and developed dedicated translation tools for various file formats (such as JSON, Markdown, and subtitle files), offering a more efficient and flexible translation experience.

Workflow: Choose a translation API → Set the source and target languages → Start translating

## Key Features

- **Translation Cache**: Automatically caches translation results locally to avoid duplicate API calls, saving time and reducing API costs.
- **Multiple Interface Options**: Offers 3 free translation methods, 3 commercial-grade translation APIs, and 5 AI LLM (large model) interfaces to meet different needs.
- **Multilingual Support & Internationalization**: Supports 35 mainstream languages (including English, Chinese, Japanese, Korean, French, German, Spanish, etc.), and can translate the same subtitle file into multiple languages simultaneously to meet international requirements.
